# 🚀 Aplicación de Tareas - Grupo CUC

**Integrantes:**
* Danilson Cassiani Camacho, Jairo Perez Tinoco, Cristian gonzales gallardo

Aplicación web desarrollada con **Next.js**, **React** y **Tailwind CSS** para la gestión de tareas (CRUD) con persistencia de datos local y sistema de papelera.

---

## ✨ Características

* **Gestión de Tareas:** Crear, editar, marcar como completadas y eliminar tareas de forma dinámica.
* **Persistencia con `localStorage`:** Los datos de las tareas activas y la papelera se guardan automáticamente en el navegador.
* **Sistema de Papelera:** Permite restaurar elementos eliminados o borrarlos de forma definitiva.

---

## 🛠️ Tecnologías

* **Next.js**
* **React Hooks** (`useState`, `useEffect`)
* **Tailwind CSS**
* **TypeScript**

---

## ⚙️ Instalación

1. Clona el repositorio:
   `git clone https://github.com/cassianidanilson9-code/BPDS`
2. Instala las dependencias:
   `npm install`
3. Ejecuta el servidor de desarrollo:
   `npm run dev`
4. Abre http://localhost:3000 en tu navegador.
